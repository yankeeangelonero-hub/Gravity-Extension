# Handoffs

This folder holds time-bound rollout notes, investigations, and live-test findings.

## Use A Handoff When

- You are mid-rollout and need to capture current findings before the design stabilizes.
- You ran a focused investigation and do not want to overload `project_memory.md`.
- You need a session-to-session bridge for work that is not yet stable enough for the permanent docs.

## Do Not Stop Here

- If a handoff contains lasting architectural truth, fold that truth back into `Documentation/project_memory.md` and the relevant component doc.
- Once a handoff is superseded, move or mirror it into `Documentation/Old/` as needed.
